# Global Stock Signal Bot

Streamlit dashboard for a 50-stock global scanner.

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Important

This V1 uses Yahoo Finance for market data. It does **not** claim that those prices equal Trade Republic / LS Exchange prices. Before using live signals for trading, connect and validate the intended EUR/LS Exchange price source.

The strategy is a technical prototype, not financial advice.
